# 🏋️‍♂️ Gym Los Makias 

Proyecto colaborativo de maquetación web estática con HTML5 y CSS3 puro para el curso de Introducción a la programación.

## 👥 Estructura y Asignaciones

1. **Landing Page (`home.html`)**: Navegación (HU001) e Instalaciones (HU002). Aplicación de Flexbox en ubicación, `scroll-snap` en carrusel y `position: absolute` en la insignia de planes.
2. **Inscripción y Pagos (`registro.html`)**: Datos (HU008) y Pagos (HU012). Uso de Flexbox para alinear los pasos/tarjetas y posicionamiento para las etiquetas de campos obligatorios.
3. **Portal Cliente (`cliente.html`)**: Perfil (HU015) y Clases (HU020). Flexbox para la parrilla de horarios y `position: absolute` para los indicadores flotantes de "Activo" o "Cupos".

## 🚀 Uso
Clona el repositorio y abre cualquier archivo `.html` en tu navegador. No requiere servidores ni dependencias.
